# ️ Liksir.ru Catalog Parser

Многопоточный и рекурсивный парсер каталога промышленной химии и масел [Liksir.ru](https://liksir.ru). 

Проект решает сложную задачу извлечения структурированных данных (цены, фасовки, наличие) из CMS 1C-Bitrix, где цены для разных вариантов товара (SKU) подгружаются динамически и хранятся в хаотичном порядке.

##  Особенности
- **Рекурсивный обход:** Автоматически находит все категории и подкатегории любой глубины вложенности.
- **Умное сопоставление (Smart Matching):** Кастомный алгоритм нормализации единиц измерения (кг, л, мл, гр) для 100% точного сопоставления цены и объёма фасовки, несмотря на нелинейный вывод HTML-тегов в Bitrix.
- **Обход защит:** Использование `curl_cffi` с эмуляцией TLS-отпечатка браузера (impersonate chrome124) для обхода базовых WAF.
- **Очистка данных:** Встроенный скрипт для дедупликации товаров, которые Bitrix размещает сразу в нескольких категориях.

##  Стек технологий
- **Python 3.10+**
- **curl_cffi** (для эмуляции браузерных отпечатков)
- **BeautifulSoup4** (парсинг HTML)
- **Loguru** (красивое логирование)
- **CSV** (экспорт данных)
