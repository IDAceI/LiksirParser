# ️ Liksir.ru Catalog Parser

Продакшн-готовый рекурсивный парсер каталога промышленной химии и масел [Liksir.ru](https://liksir.ru) на базе 1C-Bitrix.

Собирает **все товары** со всех уровней вложенности каталога, корректно сопоставляет цены с фасовками (даже для нелинейного вывода HTML от Bitrix) и сохраняет результат в CSV.

## ✨ Ключевые возможности

- **Рекурсивный обход без ограничений по глубине** — находит товары даже на 4+ уровне вложенности категорий
- **Пагинация** — автоматически проходит все страницы категории (`PAGEN_N`), собирая 100% товаров
- **Умное сопоставление фасовок и цен** — нормализует единицы измерения (`0,5 л`, `500 мл`, `18 кг`, `400 гр`) через регулярные выражения и корректно сортирует их перед склейкой с ценами
- **Ретраи с линейной задержкой** — при ошибках 429/5xx делает до 3 попыток с увеличивающейся паузой
- **Проверка статус-кодов** — логирует блокировки (403/429) вместо тихого парсинга заглушек
- **Инкрементальное сохранение** — пишет в CSV по мере работы, не теряя данные при падении
- **Возобновление после обрыва** — запоминает обработанные категории в `done_categories.txt` и продолжает с места остановки
- **Дедупликация на лету** — встроенная проверка по URL, один товар не попадает в CSV дважды даже если Bitrix разместил его в нескольких категориях
- **Обход защит** — `curl_cffi` с эмуляцией TLS-отпечатка Chrome 124
